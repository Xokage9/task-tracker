## Возможности

| | Что можно делать |
|:---|:---|
| **🗂 Проекты** | Создавать проекты, менять название и описание, управлять составом команды. |
| **📋 Доска задач** | Видеть задачи в четырёх колонках, искать по названию, фильтровать по приоритету и исполнителю «Мои задачи». |
| **🎯 Карточки задач** | Добавлять описание, назначать исполнителя, выбирать приоритет и срок, менять статус. Просроченные задачи выделяются на доске. |
| **👥 Команда** | Добавлять зарегистрированных пользователей по email. Каждый участник видит только доступные ему проекты. |
| **💬 Обсуждения** | Оставлять комментарии в карточке задачи и удалять их с учётом прав доступа. |
| **🔔 Уведомления** | Получать события о создании, изменении и удалении задач, а также новых комментариях. Читать историю и отмечать сообщения прочитанными. |
| **📊 Отчёты** | Смотреть прогресс проекта, задачи по статусам и приоритетам, просрочки и нагрузку на исполнителей. Выгружать отчёт в CSV. |
| **🔐 Аккаунт** | Регистрироваться, входить по email и паролю, работать в личном пространстве доступных проектов. |

### От идеи до результата

| К работе | В работе | На проверке | Готово |
|:---:|:---:|:---:|:---:|
| `todo` | `in_progress` | `review` | `done` |
| Запланировать | Выполнить | Проверить | Завершить |

Статус меняется в карточке. Задачу можно вернуть на любой этап, в том числе после завершения.

### Удобно в ежедневной работе

- **Обзор проекта:** общее число задач, задачи в работе, завершённые и просроченные.
- **Адаптивный интерфейс:** работа с компьютера и телефона; колонки доски прокручиваются горизонтально.
- **Надёжные уведомления:** события сохраняются вместе с изменениями задачи; при сбоях доставка повторяется без дублирования в ленте.
- **Письма по желанию:** доставка уведомлений на email после настройки SMTP.
